Wedding invitation - Anshul & Sanskriti
Open index.html in a phone browser (or host it anywhere).
Edit the CONFIG block near the bottom of index.html to add:
  PHOTOS (image URLs), CAPS (captions), AUDIO_SRC (mp3), SONG_URL (YouTube link).
For photos/music, put files in this folder and use relative paths, e.g. "photos/1.jpg", "song.mp3".
Note: the music autoplay needs the guest's tap on the book (already built in).
